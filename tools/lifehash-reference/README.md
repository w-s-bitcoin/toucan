# C++ reference tests

The JUnit tests compare image dimensions and SHA-256 hashes of raw RGB/RGBA bytes
against fixtures generated by [bc-lifehash](https://github.com/BlockchainCommons/bc-lifehash)
commit `0444dbed5615fbc9a98163608c6499c025b7873b`. Running these tests requires no C++ compiler.

The fixtures cover:

- 4,111 VERSION2 fingerprints: 15 fixed examples and the first four bytes of
  SHA-256 of UTF-8 `"SeedSigner LifeHash public test fingerprint " + i` for
  indices 0 through 4095. These use `makeFromData`, module size 1, no alpha,
  and fingerprint bytes in displayed order.
- 105 cases covering all five versions, input lengths around SHA-256 block
  boundaries, data/digest/UTF-8 entry points, Unicode, module scaling, and alpha.
- 12 exact-bit numeric cases covering palette normalization, luminance, modulo,
  and hue-sector rounding.

## C++ build

The reference uses `-std=c++17 -O3 -ffp-contract=off`. C++ results can depend on
compiler flags: FMA contraction can change white luminance from `0x1.564cdep-1`
to `0x1.564cdcp-1`, even though the tested images were unchanged. Disabling
contraction preserves the separate multiply/add rounding used by Java. Do not
use fast-math for this comparison.

The runner also passes `-include stdexcept -include cstring` for declarations
missing from the pinned source that newer libstdc++ versions require. It exports
committed source into a temporary directory without editing the reference clone.

## Compare or regenerate fixtures

Requirements: Python 3, Git, a C++17 compiler, and a Java 17+ JDK.

```sh
git clone https://github.com/BlockchainCommons/bc-lifehash.git /tmp/bc-lifehash
python3 tools/lifehash-reference/compare.py --reference /tmp/bc-lifehash
```

The runner compiles Toucan with `javac --release 17`, compares raw image bytes,
and reports the input, pixel, and channel of the first difference. Use `--cxx`,
`--java`, or `--javac` to select executables. A larger sample can be run with:

```sh
python3 tools/lifehash-reference/compare.py --reference /tmp/bc-lifehash \
  --seed 'Sparrow LifeHash C++ differential test ' --count 16384
```

To regenerate the committed fixtures, keep the default seed and count:

```sh
python3 tools/lifehash-reference/compare.py --reference /tmp/bc-lifehash \
  --write-fixtures src/test/resources/com/sparrowwallet/toucan/lifehash-reference.txt \
  --write-numeric-fixtures src/test/resources/com/sparrowwallet/toucan/numeric-reference.txt
```

Expected values come only from C++; files are written after the image comparison
passes. Review the fixture diff and rerun JUnit after regeneration. These samples
do not establish parity for every input or C++ build.
